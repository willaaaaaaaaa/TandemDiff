# Acceptance checks

Run the [core](../Tests/TandemDiffCoreTests) and [app](../Tests/TandemDiffAppTests) tests from a checkout.

```sh
swift test
./script/build_and_run.sh
```

Use the packaged app for keyboard, pointer, accessibility, and input-method checks. Use disposable fixtures and avoid running write tests on working files. Record the app revision, macOS build, architecture, filesystem, and case mode where relevant. Check saved and copied bytes with an independent reader, such as `cmp`. When an action should block, also compare directory membership and any protected metadata. See [compatibility and releases](compatibility.md) for reporting the environments you exercised.

### A08 middle-line fixture

In UTF-8, use source bytes `41 0a 58` (`A`, LF, `X`) and target bytes `41 0a 59 0a 5a 0a` (`A`, LF, `Y`, LF, `Z`, LF). Select only source line `X`, which aligns with `Y`, and copy the selected line to the target. Expect target bytes `41 0a 58 0a 5a 0a`. Undo must restore `41 0a 59 0a 5a 0a`.

## A16. Compare two trees and save one change

1. Create two local folder trees with matching LICENSE files, a distinct manifest on each side, a generated `agents/` subtree, unequal ZIPs with the same name, and two UTF-8 README files with LF terminators. In the left README, use `mode=seed` at line 12 and `ref=base` at line 284. In the right README, use `mode=leaf` and `ref=next` at the same lines. Make all other lines match. Keep independent copies of the input files.
2. Drop both roots on Home and confirm their order. Exclude `agents/` and select README. Save the named session with that selection. Verify the two unilateral manifests, **Identical** LICENSE, **Different** README, and **Not compared** ZIP.
3. Open README, enable **Context**, and navigate to the second difference. Apply only that block from left to right. Confirm that both files on disk still match the originals. Save the right pane and return to the parent comparison.
4. Compare the right README with the expected file. Only `ref=next` changes to `ref=base`. The left README, ZIPs, and excluded files keep their original bytes. The folder row remains **Different**. Reopen README and confirm that only line 12 differs.
5. Reopen the named folder session and check the roots, filter, and selected row. In a separate run, block access to a test subtree and verify that its incomplete coverage remains visible alongside the valid README result.

## Performance regression fixtures

For a scan, create 10,000 paired APFS paths with 8,000 identical 1 KiB texts, 1,000 differing texts, and 1,000 opaque pairs. For editor opening, use 50,000 short lines with 100 spaced changes and exercise a separate long-line input. Measure from acceptance of the selected inputs to the first painted, scrollable results. Count only classified folder rows and aligned text. Measure **Stop** from the user action to cancellation feedback. Record cold and warm runs separately, with the hardware, input sizes, app revision, and build configuration. Take several runs when comparing revisions and report the range as well as the median.
